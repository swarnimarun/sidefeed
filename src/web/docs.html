Reader OpenAPI JSON

OpenAPI 3.1

Add sources and feeds over HTTP.

The reader at / is read-only. Requests that change state need Authorization: Bearer <token>. Feeds marked public can be read without a token.

Adding a feed the reader can show is two calls: create the feed with public: true and connect a source to it. See the OpenAPI document for schemas.

Example

curl -sS -X POST https://your-host/api/v1/sources -H 'authorization: Bearer $TOKEN' -H 'content-type: application/json' -d '{"url":"https://example.com/feed.xml"}'

curl -sS -X POST https://your-host/api/v1/feeds -H 'authorization: Bearer $TOKEN' -H 'content-type: application/json' -d '{"slug":"reading","title":"Reading","public":true}'
